# 闭包

**闭包是指有权访问另一个函数作用域中变量的函数**。闭包主要用于**数据封装（模拟私有变量）和保持状态**（如柯里化函数、计数器）。

例子：

```js
function createCounter() {
  let count = 0; // 这个变量在 createCounter 执行完后本该销毁

  return function() { // 这个返回的函数就是闭包
    count++;
    console.log(count);
  };
}

const myCounter = createCounter();
const anotherCounter = createCounter();

myCounter();
myCounter();
anotherCounter();
```

myCounter和anotherCounter中的count是互不影响的。这是因为 JS 中函数每**执行**一次，就会创建一个全新的**执行上下文**，它们内部的 `count` 变量在内存中是两个完全独立的地址，所以互不影响。
